## ЭФФЕКТЫ (13)

**A1. Искры при закрытии вкладки.** Контракт от GLM: при закрытии в #navigator-toolbox появится `div.blade-ghost` (absolute, позиция вкладки, авто-удаление через 600мс). Твоя часть: CSS — карточка-призрак с быстрым угасанием (opacity) + 5-7 «искр» (маленькие div ИЛИ один элемент с multiple box-shadow, разлёт через transform в keyframes; только transform/opacity). Стиль — акцентный, в духе клинка.

**A2. Разрез при открытии новой вкладки.** Новая вкладка влетает (существует blade-tab-in «влёт») — добавь по её .tab-background диагональный слэш-блик (тот же приём, что на плитках: translateX ±130% со skewX), однократный, 0.4s. Триггер — тот же, что у влёта (посмотри, как он выбирает новые вкладки).

**A3. Волна смены темы/облика.** При смене темы цвета хрома меняются мгновенно. Добавь плавность: `transition` (не keyframes!) на background-color/border-color/color основных поверхностей — тулбокс, навбар-капсула, вкладки, часы (0.45s ease) — смена темы станет перековкой, а не телепортом. Не трогай ::selection (там literal-цвета из-за bug 1343967) и USER_SHEET контентную часть.

**A4. Пульс окна на события.** Контракт от GLM: на `<html>` на 900мс вешается класс `blade-flash` (скачали файл / встал апдейт). CSS: по `.blade-flash` рамка тулбокса (существующая кайма окна через маржины) и/или линия тулбокса получают короткую вспышку яркости (animation 0.9s, opacity 0→1→0) — свет встречается со звуком chime.

**A5. Периодический блик по кнопке B.** Кнопка `#bobliks-settings-button` (у неё ребёнок `.toolbarbutton-icon` занят тем-анимациями!). Добавь редкий само-блик: НОСИТЕЛЬ — сама кнопка `#bobliks-settings-button::after` (проверь свободу!) — тонкая полоска света пробегает по кнопке каждые ~18s (animation с длинным пустым циклом, 6% времени — блик, 94% — покой; transform+opacity).

**A6. Разрядка капсулы.** При завершении загрузки страницы — по адресной капсуле (`.urlbar-background` — КЛАСС, не id!) пробегает мягкая волна. Триггер: у урлбара гаснет `[focused]`? Нет — загрузка связана с табом `[busy]`. Проще: усиль существующую связку — при переходе активной вкладки из busy в не-busy мигни. Реализация: `tab:not([busy]) .tab-background` уже занято темами… тогда носитель — капсула: `#urlbar` получает стили от `:has(.tabbrowser-tab[busy])`? — НЕЛЬЗЯ (урлбар не потомок таба). Контракт от GLM: на `<html>` класс `blade-loaded` на 500мс при окончании загрузки активной вкладки. CSS: `.blade-loaded .urlbar-background` — короткая вспышка яркости бордера (opacity/glow, 0.5s).

**A7. Воспламенение короны.** Активная вкладка носит ромб-корону (найди секцию «корона» в userChrome). Добавь: при ПЕРЕКЛЮЧЕНИИ вкладки корона вспыхивает — носитель `.tab-background::before` ромба (проверь, чем он рисуется) получает one-shot вспышку (scale 1.6→1 + opacity 1→0.9, 0.35s) — сработает при появлении [selected] у новой вкладки (CSS-анимации стартуют при применении селектора ✓).

**A8. Шиммер нового окна.** Каждое НОВОЕ окно (не первый старт): быстрая световая волна по тулбоксу один раз. Носитель — придумай из свободных (например `#navigator-toolbox` сам — невозможно, псевдо заняты; попробуй `#nav-bar::before` — проверь занятость капсульными стилями! или инъекция через Settings — НЕТ, только CSS). Если носителя нет — предложи в отчёте контракт-класс `blade-newwin` от GLM на `<html>` (снимается через 700мс), и верстай под него.

**A9. Звёздная пыль приватных вкладок.** В приватных окнах корень имеет атрибут `[privatebrowsing]`. CSS: `html|html[privatebrowsing] .tabbrowser-tab .tab-background` — едва заметные мерцающие искорки (2-3 точки через background multiple radial-gradient, twinkle через opacity-анимацию с разными delay — 3-4s циклы). Деликатно: opacity пиков ≤ 0.5.

**A10. Погодный глиф в часах.** Контракт от GLM: в виджет часов добавится `span.blade-weather-glyph` с текстом-символом (☀ ☂ ❄ ⚡ ☁ ✨) по виду погоды. Твоя часть: стили — размер как у текста часов, лёгкое акцентное свечение, плавная смена (opacity transition невозможен при смене текста — не важно, просто стилизуй), при «ясно днём» глиф тёплый, ночью ✨-звёзды холодные.

**A11. Карточка при драге вкладки.** При перетаскивании вкладки Firefox ставит `[dragged]`? — проверь в движке (browser.xhtml/tabs.js), если нет — используй `_dragOver`/hover-приёмы или предложи контракт. CSS: тащимая вкладка = светящаяся карточка: accent-рамка, лёгкий наклон rotate(2deg), подъём translateY(-2px), тень глубже. Только transform/статика.

**A12. Пульс ввода в палитре.** В PALETTE_CSS (BladePalette.uc.js): рамка панели `#blade-palette::part(content)` при фокусе инпута... пульс на КАЖДУЮ клавишу CSS не поймает. Контракт от GLM: класс `blp-typing` на wrap на 300мс (debounce). CSS: `.blp-typing` — акцентная рамка чуть ярче + мигающий индикатор-курсор в углу футера (если найдёшь свободный носитель в структуре палитры — прочитай её разметку в JS).

**A13. Закатная волна 22:00.** Хук существует: `[data-blade-night]` на `<html>` (22:00–6:00) + ночные дельты тем уже в CSS. Добавь плавность: transition (0.8s ease) на ночных переопределениях переменных-потребителей (background-color/border-color тулбокса, капсулы, вкладок) — ночь будет НАКАТЫВАТЬ, а не щёлкать. Проверь, что утро (снятие атрибута) тоже плавное.
