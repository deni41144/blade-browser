# Blade — Свой знак

Исправлен полный путь фирменного значка Windows. Значок Blade применяется к самому окну браузера, а launcher теперь входит в установщик и корректно устанавливается в корень браузера.

- Кнопка «Запустить Blade», ярлыки меню «Пуск» и рабочего стола теперь запускают Blade через фирменный launcher.
- Обновление переносит новый launcher в установку и исправляет старые ярлыки Blade и закреплённые ссылки, только если совпадают путь движка и профиль.
- Удаляется только подтверждённый устаревший дубль ярлыка Blade; чужие ярлыки и выбор браузера по умолчанию не меняются.
- Удаление Blade очищает принадлежащие этой установке ярлыки и ждёт, пока процесс значка штатно завершится.
- Оформление браузера и оригинальный значок Blade сохранены.

## Blade — Our Mark

Fixed the complete Windows branding path. Blade's icon is applied to the browser window itself, and the launcher is now included in Setup and deployed to the browser installation root.

- The Setup launch button, Start Menu and Desktop shortcuts now launch Blade through its branded launcher.
- Updates deploy the new launcher and repair existing Blade shortcuts and pinned taskbar links only when both the engine path and profile match this installation.
- Only a confirmed obsolete duplicate Blade shortcut is removed; unrelated shortcuts and Windows default-browser choices are preserved.
- Uninstall removes shortcuts owned by this installation and waits for the icon watcher to exit cleanly.
- Browser visuals and the original Blade icon are preserved.
