# Blade — Свой знак: микропатч

Исправлен запуск со старого ярлыка рабочего стола: он больше не обходит фирменный launcher, который назначает окну значок Blade.

- Помощник значков восстанавливает старые обычные ярлыки этой установки при запуске браузера и смене темы.
- Сохраняется выбранный цвет значка; параметры веб-приложений, приватного просмотра и ссылки на другие профили не перенаправляются.
- Исправление включено в обновление, полный пакет и новый офлайн-установщик.

После обновления перезапустите браузер. Название Firefox в диспетчере задач относится к подписанному движку Mozilla; значок окна и ярлыка — Blade.

## Blade — Our Mark: hotfix

Fixed legacy desktop shortcuts bypassing the branded launcher that applies the Blade window icon.

- The icon helper repairs plain shortcuts belonging to this installation on browser startup and theme changes.
- The selected icon color is preserved. Web-app arguments, private browsing shortcuts and other profiles are not redirected.
- Included in the update, full package and rebuilt offline Setup.

Restart the browser after updating. Windows Task Manager still identifies the signed Mozilla engine as Firefox.
