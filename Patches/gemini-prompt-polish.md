## Кто такой Blade (контекст стиля)

Тёмный кибер-браузер с демоническим характером: акцент — кровь-красный
`var(--accent, #ff2a2a)`, переключается темами (10 штук: blood/purple/green/
grey/orange/cherry/midnight/volt/custom — все через переменные). Типографика:
Unbounded (display, заголовки), Rubik (текст), JetBrains Mono (терминальные
элементы). Звук и хром уже в стиле GX. Всё, что ты делаешь, должно звучать
с этим миром: тьма, контраст, острые углы там где уместно, свечение акцента.

## Конвенции проекта (нарушить нельзя)

1. В `@keyframes` ТОЛЬКО `transform` и `opacity`. `filter`/`box-shadow` —
   только статикой. Никакого `backdrop-filter` на постоянных поверхностях
   (попапы можно).
2. Цвет — только через переменные: `var(--accent, #ff2a2a)`,
   `var(--accent-soft, rgba(255,42,42,0.35))`, `var(--panel, #14141a)`,
   `var(--text, #e8e8e8)`. Никаких хардкодов цветов.
3. Селекторы движка сверены и работают (не выдумывай свои без нужды):
   - читалка: `about:reader` → `.moz-reader-content`, body классы парсера;
   - PDF-просмотр: `#viewerContainer`, `.pdfViewer`, Lit-Shadow DOM у
     тулбара (внешние правила до тулбара НЕ доедут — только к body/html);
   - печать: `@media print` в userContent.css;
   - меню Blade (панель настроек): `#bobliks-settings-popup`, вкладки
     `.bp-tab`, тело `.bp-body`;
   - палитра Ctrl+K: `.blp-wrap`, `.blp-row`, инпут `.blp-input`.
4. Ночной режим: `:root[data-blade-night]` — ночью интерфейс мягче/темнее.
5. Режим экономии: `:root[data-blade-battery]` — анимации гаснут, твои
   новые анимации обязаны гаснуть тоже (селектор уже режет `#blade-hero
   .bh-clock` и дрифты — добавляй своё в ту же механику).

## Задачи волны

1. **about:reader (режим чтения).** Сейчас — ванильный Firefox. Сделай
   читалку в стиле Blade: тёмный фон `#0e0e12`-глубины, акцентные ссылки,
   комфортная типографика (Rubik для текста, Unbounded для заголовка статьи),
   мягкая ширина колонки. Нужен и светлый вариант для дня? Нет — Blade тёмный
   всегда, но контраст текста сделай щадящим для долгого чтения.
2. **PDF-просмотрщик.** Тёмный фон `#viewerContainer` (сейчас серый),
   акцентный выделенный текст, тулбар тонируется чем можно достучаться
   (body/html уровень).
3. **Печать (@media print).** Проверь и почини: печать страниц не должна
   тащить тёмные фоны и тени (белый лист, чёрный текст, скрытые наши
   декорации).
4. **Меню B (#bobliks-settings-popup).** Анимация открытия/закрытия панели
   (compositor-only!), hover-состояния всех строк, фокус-ринг клавиатурной
   навигации с акцентным свечением.
5. **Палитра.** Пустое состояние поиска («ничего не найдено — ❯ ...»),
   лёгкий пульс инпута при открытии.

нужен живой DOM-факт, которого нет выше, — пометь `[НУЖЕН ФАКТ: ...]`,
не выдумывай селекторы.
