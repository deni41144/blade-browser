# Blade — Свой знак: поиск

Восстановлено оформление выпадающего поиска Blade после обновления движка.

- Панель использует материал выбранной темы, цветной контур и скругления.
- Новая внутренняя подложка Firefox больше не перекрывает оформление Blade.
- Длинный список подсказок ограничен по высоте и прокручивается в актуальной разметке Firefox 158.
- Исправление входит в обновление, полный пакет и новый офлайн-установщик. Исправления плиток и ярлыков предыдущих выпусков сохранены.

После обновления перезапустите Blade.

## Blade — Our Mark: search

Restored Blade's address suggestion panel styling after the engine update.

- The panel uses the selected theme material, accent border and rounded corners.
- Firefox's new inner background no longer covers Blade's styling.
- Long suggestion lists have a height limit and scroll using the current Firefox 158 markup.
- Included in the update, full package and rebuilt offline Setup, alongside the previous tile and shortcut fixes.

Restart Blade after updating.
