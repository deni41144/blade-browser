## Что это
Кастомный браузер Blade на движке Firefox 155 (2026): брендинг-хирургия omni.ja,
тёмный демонический стиль, свой апдейтер/сетап/звук/палитра. Автор: Denis
Bobliksov (Blade-Creations). Друзья получают обновления автоматически через
репозиторий (BladeUpdater проверяет releases/latest раз в сутки).

## Типовые операции
- **Проверить здоровье после правок:** `Blade-Eyes.ps1 -Full` → свежий отчёт
  (Пульс GREEN = контракт/узлы/шрифты живы; скрины — для глаз владельца/Гемини).
- **Собрать релиз без публикации:** `Publish-Blade-Update.ps1 ... -SkipPublish`
  (патч) или `... -Mode Full -SkipPublish` (+движок). **Публикация — только по
  слову владельца «публикуй».**
- **Прогнать браузер на изменениях:** `Blade-Eyes.ps1 -Start` → (прогулки) →
  `-Shot "имя"` → `-Stop` → `-Collect`. Путь с пробелами — кавычки внутри
  строки аргументов (конвенция 13, PS 5.1).

## Железные правила
1. **Конвенции 1–34 из PROJECT_MAP.md** — нарушать опасно (там грабли с
   описанием). Кратко о самых частых:
   - **33/34 (СТИЛИ В XUL):** стили для HTML-нод интерфейса (эффекты, urlbar,
     ::selection) — **только AUTHOR-инъекцией** `<style>` в
     `document.documentElement` из того же .uc.js (паттерн
     `BobliksChromeStyle.uc.js` / `BladeWindowFx.uc.js`). `userChrome.css`
     грузится USER_SHEET'ом, который в XUL-документе **не достаёт HTML-нод** —
     правила молча не матчятся, а `html|`-префикс в AUTHOR-`<style>` невалиден
     без `@namespace html`. Единственное, что живёт в userChrome.css, — XUL.
   - **6:** `@keyframes` только `transform`/`opacity`.
   - **28(4):** меню-стили в AUTHOR-листе требуют `var(--bob-accent, #ff2a2a)`.
   - **2:** каждый .uc.js пишет `chrome\JS\<Name>_mark.txt` — первая
     проверка здоровья по файлу.
2. **Правило владельца:** использовать ВСЕХ агентов по надобности — Explore
   (разведка/поиск), Analyst (карты), BackendEngineer (сервер/логика),
   FrontendDesigner (CSS/UI), QAReviewer (проверки/тесты). Главный агент —
   оркестратор: сам гоняет grep/glob по проекту и пишет нетривиальный код
   только в исключениях. Компьютер-управление — только главный агент.
3. **Дизайн-мандат:** визуальные изменения — только через Gemini (промпты в
   `Patches\gemini-prompt-*.md`), оркестратор — инженерия и верификация.
4. Живой профиль C: и публикация — только по явному слову владельца.
5. Сомнение = git revert, а не «и так сойдёт». Волна = коммит.
6. Вето-фильтр фич (конвенция 12): никакой ерунды «для галочки».
