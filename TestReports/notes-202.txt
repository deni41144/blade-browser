--- English ---

Fixes:
— The B-button no longer disappears: moved to direct DOM mounting (the engine never built the widget node in fresh installer profiles)
— Fixed full-package auto-updates: the applier no longer locks the engine folder with its own working directory («failed to remove the old engine»), with retries and archive integrity checks added
— Restored the user-script loader in the engine config.js
— Profile Guard no longer hijacks the default profile when launched with an explicit -profile flag
— Russian language out of the box for fresh installs (langpack bundled, the installer wires it up)

This is a customization-only update (~8 MB), the engine is not replaced. If the full-package auto-update failed with «failed to remove the old engine» — just check for updates again: this patch applies without touching the engine and fixes the update mechanism for the future. For the Russian UI reinstall via Blade-Setup 1.4.2+.
