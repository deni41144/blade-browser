# BLADE — КАК НАЧАТЬ (для тех, кто не кодер)

Привет! Тут всё, чтобы запустить Blade и начать работать. Никакого сложного —
просто повторяй шаги по порядку. Если что-то непонятно — копируй блок
«ПРОМПТ ДЛЯ НЕЙРОНКИ» из файла `НЕЙРОНКЕ.md` в свою Atria, она сделает сама.

---

## ШАГ 1. Забери пакет (то, что тебе передали)
Тебе дали один файл:

```
Blade-Workstation-v2.0.8.zip
```

Распакуй его в любую папку на диске, например `C:\Blade`. **Не распаковывай
поверх установленного Blade**, если он у тебя уже стоит — сделай отдельную
папку, чтобы ничего не сломать.

Внутри будет:
- `Blade-Full-v2.0.8.zip` — сам браузер (движок + весь наш код)
- `КАК-НАЧАТЬ.md` — этот файл
- `НЕЙРОНКЕ.md` — промпт для твоей нейронки
- `Blade-Full-v2.0.8.zip.sha256` — для проверки, что файл не повредился

---

## ШАГ 2. Распакуй браузер
Внутри `Blade-Workstation-v2.0.8.zip` лежит `Blade-Full-v2.0.8.zip`.
Распакуй его тоже (правый клик → Извлечь). Появится папка с двумя подпапками:

```
App\Firefox64\      ← движок браузера
profile\            ← вся наша кастомизация (темы, эффекты, код)
```

---

## ШАГ 3. Запусти
Зайди в `App\Firefox64\` и дважды кликни **`firefox.exe`**.

Должен открыться Blade — тёмный, с темой GX Red по умолчанию, часами на новой
вкладке и кнопкой **B** в панели слева вверху. Если открылось — поздравляю,
всё работает.

> **Проверь себя:** закрой любую вкладку средним кликом мыши (колёсиком) по ней.
> Вкладка должна **распылиться** — искры, осколки, кольцо ударной волны. Если
> просто исчезла — скажи, значит код применился не полностью.

---

## ШАГ 4. Где живёт код (если захочешь поменять)
Вся кастомизация — в папке `profile\chrome\`:

| Папка / файл | Что внутри |
|---|---|
| `chrome\JS\*.uc.js` | Вся логика на JavaScript (темы, меню, эффекты, часы) |
| `chrome\userChrome.css` | Стили интерфейса браузера (тулбар, вкладки) |
| `chrome\userContent.css` | Стили сайтов и новой вкладки |
| `chrome\img\` | Все картинки: обои тем, обложки, иконки |
| `chrome\fonts\` | Шрифты для часов и заголовков |
| `profile\user.js` | Настройки браузера (приватность, скорость) |

**Главный файл для эффектов:** `chrome\JS\BladeWindowFx.uc.js` — распыление
вкладок, волна при смене темы, вспышка при переключении вкладки.

**Главный файл для новой вкладки:** `chrome\JS\BladeNewtab.uc.js` — часы,
погода, плитки, атмосферные частицы.

## ШАГ 5. Исходники на GitHub (для совместной работы)
Код хранится в закрытом репозитории. Ты уже добавлен как участник
(collaborator), так что у тебя есть доступ.

1. Поставь Git, если его нет: открой PowerShell и введи
   `winget install Git.Git`, потом перезапусти PowerShell.
2. Склонируй репозиторий:
   ```
   git clone https://github.com/deni41144/blade-browser.git
   ```
3. Спросят логин-пароль GitHub — используй свой аккаунт (вулфик).

Подробно — см. файл `НЕЙРОНКЕ.md`, там готовый промпт, который всё это
сделает за тебя через твою нейронку.

## ⚠️ ТРИ ЖЕЛЕЗНЫХ ПРАВИЛА (не нарушай)

1. **Не публикуй релизы.** Обновление уходит всем друзьям автоматически.
   Публикация — только по слову владельца (Дениса).
2. **Не трогай папку `C:\Users\...\AppData\Local\Blade`** — это боевой
   браузер владельца. Там его личные данные. Если она есть на твоём компе —
   просто не заходи.
3. **Не удаляй код, чтобы убрать ошибку.** Разбирайся в причине или спроси.

Если сомневаешься — лучше спросить, чем сломать. Откатываться можно через
`git revert`, «и так сойдёт» не подходит.
