# Blade original theme sounds · 3.1.0

60 original mono PCM WAV sound effects, authored from scratch for 10 themes and 6 UI actions. No keyboard recording, downloaded sample, Opera audio, or previous Blade sound is an input. Rebuild with TestReports/generate_custom_sounds.py from the workspace root (Python + NumPy).

Each recipe is an original short broadband textured click, defined by its own colour spectrum and attack/decay. No tonal oscillator, pitched note, drum body or resonant tail. Sub-500 Hz energy is kept below 1%, high treble is restrained. Files last 45–80 ms with smooth edges, RMS alignment and a separate 0.45 peak ceiling. Runtime only reads and plays WAVs and applies volume/event gains. Manifest records exact parameters and SHA256 values. Subjective approval remains with the owner.

A fal audio generation attempt was rejected before submission due to zero account credits; no generated fal output is part of this set.
