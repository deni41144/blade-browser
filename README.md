# Blade Browser

Приватная сборка браузера Blade. Распространение — по ссылке от владельца репозитория.

## Обновления

Браузер проверяет обновления автоматически раз в сутки.
Ручная проверка: меню **B → Обновления → Проверить сейчас**.

Обновление ставится в один клик: браузер сам скачивает пакет, закрывается,
применяет его (с бэкапом в папке `Backups`) и запускается обратно.

## Ручное обновление (если автообновление недоступно)

1. Скачать `Blade-Patch-vX.Y.Z.zip` из [Releases](../../releases)
2. Распаковать архив целиком
3. Запустить `UPDATE.bat` из папки архива
4. Перезапустить Blade
